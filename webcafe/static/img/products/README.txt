Put your own product photos in this folder.

1. Name the file after the product, e.g.  club-sandwich.jpg
   (JPG, PNG or WEBP; a square photo on a white background looks best, 1200 x 1200 px is plenty)
2. Open webcafe/data/products.json, find that product and add one line next to its "name":
       "image": "img/products/club-sandwich.jpg",
3. Save and refresh the website.

To go back to the drawn picture, delete the "image" line.
If the file name is wrong, the site automatically shows the drawn picture instead.
